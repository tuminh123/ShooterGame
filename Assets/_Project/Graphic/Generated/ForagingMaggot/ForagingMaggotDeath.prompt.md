# Foraging Maggot death sprites

Created with the built-in image generation tool, using the existing `ForagingMaggot.png` live sprite strip as the identity/style reference. The source art is unchanged.

Prompt:

Create a production game pixel-art death animation SPRITE SHEET for the exact small gray/ivory maggot creature shown in the reference sprite strip. Reference role: existing live creature identity and pixel art style; create new death poses, do not redesign the creature. Output a 1536 by 1024 transparent PNG arranged as EXACTLY 3 columns by 2 rows of identical 512x512 square cells, no margins between cells, no labels, no grid lines. Six frames ordered left-to-right then top-to-bottom. Every cell contains the same tiny side-view segmented ivory/gray maggot with a small ochre/yellow face at its RIGHT end and dark charcoal pixel outline, same facing and body proportions as the reference. Match its restrained palette and very low resolution classic game pixel style: model each cell as a logical 16 by 16 pixel tile enlarged with sharp nearest neighbor pixel blocks, NOT high-resolution illustration, NO smooth gradients or antialiasing. Character bounds roughly columns 1..14 and rows 6..14 of each logical tile; feet/body baseline fixed at logical y=14 in every cell (bottom margin 1 pixel). Keep the same cell registration and ground contact, no whole-body translation or spin or flight. Animation: frame1 hit flinch with body arches slightly; frame2 tense curl and compressed segments; frame3 sagging slump beginning; frame4 body collapses lower with face dropping; frame5 flattened lifeless body, closed eye; frame6 final settled flattened lifeless body, matching prior width, no blood, no debris, no explosion, no text. Character remains clearly the same gray maggot across all frames, preserve silhouette and sparse shading. Genuine alpha transparency everywhere outside sprites.

Unity setup: six square cells, ordered across the top row then the bottom row; Point filtering, no compression/mipmaps, 2560 pixels per unit, pivot `(0.5, 0.078125)`. The visual prefab plays the frames at 12 fps, for 0.5 gameplay seconds total.
